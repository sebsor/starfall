# STARFALL

*Something was here before us.*

A neon retro side-scrolling space shooter: pick your route across a star chart, fight through sectors and guardians, collect upgrades, and face the Custodian at the Elder Ruins. A story that isn't over yet.

**Play:** open `index.html`, or visit the GitHub Pages site for this repository.

## Controls
| | |
|---|---|
| Arrows / WASD | Move |
| Space | Fire |
| Mouse / touch | Hold and drag to move (auto-fire) |
| P / Esc / the PAUSE switch | Pause menu: music and effects volume, screen shake, reduce flashing, controls, quit run |
| M / N | Sound / music on-off |
| F | Fullscreen |
| Shift / double-tap a direction / right-click / two-finger tap | Phase Dash (Wraith, or once you've picked that upgrade) |
| Esc or the SKIP button | Skip the walk up to the arcade machine |
