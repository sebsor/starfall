# STARFALL

*Something was here before us.*

A neon retro side-scrolling space shooter in a single HTML file: three sectors, three bosses, a story that isn't over yet.

**Play:** open `index.html`, or visit the GitHub Pages site for this repository.

## Controls
| | |
|---|---|
| Arrows / WASD | Move |
| Space | Fire |
| Mouse / touch | Hold and drag to move (auto-fire) |
| P | Pause |
| M / N | Sound / music on-off |
| F | Fullscreen |

## Music
Original soundtrack by Sebastian. The tracks live in [`music/`](music/).
If a file is missing, the game falls back to its built-in synthesized music for that track.

| Track | Plays during |
|---|---|
| First Contact | Start screen, prologue, title, story chapters |
| Nebula Arpeggio | Level 1 · Stardust Reaches |
| Galactic Arpeggio | Level 1 boss · The Starwhale |
| Void Navigation | Level 2 · The Hollow |
| Orbital Boss Rush | Level 2 boss · The Hollow Eye |
| The Frame Drum's Pulse | Level 3 · The Elder Ruins |
| The Chronos Leviathan | Level 3 boss · The Custodian |
| Beyond the Event Horizon | Ending and end credits |
